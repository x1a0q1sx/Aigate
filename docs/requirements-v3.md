# AI Gate v3 — 需求规格说明书
## 1. 项目概述
### 1.1 背景
当前 AI 模型服务商众多（OpenAI、Anthropic、Google、硅基流动、DeepSeek、GitHub Models 等），
每个服务商有不同的 API、密钥、模型和定价。用户需要一个**统一网关**来：
- 管理所有服务商和密钥
- 自动选择最优模型响应请求
- 对收费/免费模型进行灵活参与控制
### 1.2 目标
构建一个轻量级本地 AI API 网关，对外暴露 OpenAI 兼容接口，
对内自动路由到最优 AI 模型。

## 3. 功能需求
### 3.1 服务商管理
- 支持手动添加服务商（名称、Base URL、API Key）
- 支持服务商预设模板（OpenAI、Anthropic、Google、硅基流动、DeepSeek、GitHub Models 等）
- 支持一键测试服务商连通性
### 3.2 模型发现与定价
- 调用服务商 `/v1/models` 接口获取模型列表
- 调用服务商 `/v1/models/{id}` 或定价接口获取价格信息
- 自动识别免费模型（price == 0）并标记
- 手动设置/修正模型价格
### 3.3 Auto 路由引擎
- **定时评测**：每隔 N 分钟（可配置，默认10分钟）对所有候选模型进行轻量评测
  - 发送测试 prompt（如"你好"）
  - 记录：延迟(ms)、可用性、token 生成速度
- **评分算法**：
  ```
  score = 可用性权重(40%) + 低延迟权重(30%) + 高速度权重(30%)
  收费模型：score = score * 0.8(价格惩罚因子)
  ```
- **选举范围**：
  - 免费模型 → 自动加入选举池
  - 收费模型 → 用户勾选后才加入选举池
- **auto 调用流程**：
  1. 用户请求 model=`auto`
  2. 网关从选举池中取当前评分最高的模型
  3. 若高可用模式开启，取 Top-3 做负载均衡
  4. 转发请求并返回
### 3.4 API 接口
#### OpenAI 兼容接口（外部）
- `POST /v1/chat/completions` — 聊天补全（支持 model=`auto`）
- `POST /v1/completions` — 文本补全
- `GET /v1/models` — 列出所有可用模型
- `POST /v1/embeddings` — 嵌入
#### 管理面板 API
- `GET/POST/PUT/DELETE /api/admin/providers` — 服务商 CRUD
- `GET/POST/PUT/DELETE /api/admin/keys` — 密钥 CRUD
- `GET /api/admin/models` — 模型列表（含价格、自动选举状态）
- `PUT /api/admin/models/:id/auto` — 开关收费模型的 auto 参与
- `GET /api/admin/stats` — 请求统计与延迟数据
- `POST /api/admin/test` — 测试服务商连通性
### 3.5 Web 管理面板
- 仪表盘：总请求数、成功率、平均延迟、活跃服务商数
- 服务商管理：添加/编辑/删除/测试
- 密钥管理：多密钥轮换
- 模型管理：查看模型、定价、参与 auto 开关
- 日志查询：请求记录、错误日志

## 4. 非功能需求
| 需求 | 指标 |
|------|------|
| **性能** | 网关转发延迟 < 50ms (不含上游模型耗时) |
| **可用性** | 单个服务商故障不影响其他服务商 |
| **可扩展** | 新增服务商无需改代码，配模板即可 |
| **安全** | API Key 加密存储，管理面板需鉴权 |
| **兼容性** | 100% OpenAI Python SDK / cURL 兼容 |
---
## 5. 系统约束
- **后端**：Python 3.12+，FastAPI + SQLAlchemy + SQLite
- **前端**：Vue 3 + Vite（可复用 aigate 现有前端框架）
- **部署**：单机本地运行，pip install + 一键启动
- **定时任务**：APScheduler
